# Representative playable game scene

<badge>Draft evaluation pack</badge>

This is a **design skeleton**, not yet a calibrated or directly scoreable benchmark.

- [Pack manifest](pack.yaml)
- [Rubric draft](rubric.yaml)
- [Evaluation instructions](evaluation.md)

The pack evaluates a scene that expresses the intended visual direction, spatial organization and core interaction. A real project, fixed design brief, reference versions, playable build and player path must be selected before the rubric can be calibrated.

A static screenshot is insufficient to claim playability. Different styles may have multiple valid outcomes; a single image is not a universal golden answer. Calibrate rubric anchors with a real project before scoring.
