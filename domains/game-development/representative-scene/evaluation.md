# Evaluation instructions

1. Pin the design brief, reference materials, scene commit and player path.
2. Record model, host, skills, tools, engine version and budget.
3. Collect playable build, graybox/final scene, resource provenance and playtest notes.
4. Run the build and complete the agreed player path.
5. Evaluate design intent, visual coherence, spatial readability, interaction, audio and technical quality separately.
6. Record evaluator, evidence, disagreements and untested areas.
7. For comparisons, keep task scope and rubric stable where possible.

This pack is not calibrated. Complete the rubric anchors on a representative project before formal use.
