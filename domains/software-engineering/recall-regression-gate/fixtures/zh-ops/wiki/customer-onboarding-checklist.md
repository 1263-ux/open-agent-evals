# 新客户上线检查清单

## 上线前（T-7 天）

- [ ] 合同与订单录入，租户开通，确认套餐与配额
- [ ] 域名与证书：自定义域名解析、HTTPS 证书签发
- [ ] SSO 接入完成并通过测试账号验证（见「单点登录接入」）
- [ ] 初始管理员账号创建，至少两人，避免单点
- [ ] 数据导入方案确认：字段映射表、样例数据试导

## 上线前（T-1 天）

- [ ] 验收用例全部通过，客户签字确认
- [ ] 培训完成：管理员培训 1 场、终端用户培训 1 场
- [ ] 告警与通知配置：客户联系人、值班电话、告警群
- [ ] 回滚方案确认：数据导入失败如何回退

## 上线当天

- [ ] Go-live 确认会，双方负责人同时在线
- [ ] 观察 2 小时核心指标：登录成功率、接口错误率、导入进度
- [ ] 首日问题清单建立，24 小时内闭环

## 上线后（T+7 天）

- [ ] 回访，收集问题与改进项
- [ ] 使用率报告：活跃用户、核心功能使用占比
- [ ] 转为常规支持，移交给客户成功经理

## 判定

清单未完成项超过 3 项不允许上线；SSO 与初始管理员为**硬性前置**，
缺一不可放行。
