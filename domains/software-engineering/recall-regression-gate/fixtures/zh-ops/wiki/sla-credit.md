# SLA 违约补偿规则

## 补偿档位

按当月可用性相对承诺值的差距计算，以**月度服务费**为基数：

| 实际可用性 | 抵扣比例 |
| --- | --- |
| 低于承诺但 ≥ 99.5% | 10% |
| 99.0% – 99.5% | 25% |
| 低于 99.0% | 50% |

单月补偿上限为当月服务费的 50%，不跨月累计。

## 申请

- 客户需在事发次月 **30 天内**提交工单申请，逾期视为放弃。
- 我方主动发现的故障，无需客户申请，直接在下期账单抵扣。
- 申请需附故障时间与受影响接口，我方以监控数据为准。

## 与其他条款的关系

- 补偿**不与退款叠加**：已按「退款政策」退款的订单不再计算 SLA 抵扣。
- 补偿以抵扣券形式发放，不可提现、不可转让、不开发票。
- 因客户自身配置错误、超出配额被限流导致的不可用，不计入违约。
