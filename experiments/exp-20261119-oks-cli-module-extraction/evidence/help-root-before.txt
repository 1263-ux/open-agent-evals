│                 report.                                                     │

│ skills          Manage Skills under Wiki: import, review, search and load   │
│                 on demand.                                                  │

│ config          Global configuration (~/.oks/config.json).                  │
│ hook            Optional editor hooks for recall, conflict detection,       │
│                 collaboration, and workflow.                                │

│                 sources.                                                    │
