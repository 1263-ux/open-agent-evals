##### init --help
                                                                               
 Usage: python -m knowledge_studio.cli init [OPTIONS] {path}                   
                                                                               
 Scaffold a new knowledge INSTANCE folder (e.g. your personal                  
 artboy-knowledge-studio).                                                     
                                                                               
 Creates the bucket structure and a .gitignore that TRACKS your memory         
 (wiki/, drafts/, profiles/) while ignoring only per-machine state (.oks/).    
 Points ~/.oks/config.json at the new folder only when no active KB is         
 registered yet; pass --set-default to switch an existing one.                 
                                                                               
┌─ Arguments ─────────────────────────────────────────────────────────────────┐
│ *    path      <str>  Target directory for the new knowledge instance       │
│                       [required]                                            │
└─────────────────────────────────────────────────────────────────────────────┘
┌─ Options ───────────────────────────────────────────────────────────────────┐
│ --set-default    --no-set-default      Register this folder as the active   │
│                                        KB in ~/.oks/config.json. Default:   │
│                                        only when no active KB is registered │
│                                        yet                                  │
│ --git            --no-git              Run `git init` in the instance       │
│                                        folder                               │
│                                        [default: git]                       │
│ --upgrade                              Refresh bundled skills and hooks;    │
│                                        preserve existing knowledge and      │
│                                        settings, and add missing defaults   │
│ --force                                Scaffold into a non-empty directory  │
│                                        that is not already a knowledge base │
│ --help                                 Show this message and exit.          │
└─────────────────────────────────────────────────────────────────────────────┘

##### team init --help
                                                                               
 Usage: python -m knowledge_studio.cli team init [OPTIONS] [path]              
                                                                               
 Create a shared team instance on top of the normal OKS scaffold.              
                                                                               
 Team knowledge is still stored as tracked Markdown under profiles/, raw/,     
 wiki/, and drafts/. This command only adds an explicit team-oriented entry    
 point and creates a minimal team profile; goals are created by the user.      
                                                                               
┌─ Arguments ─────────────────────────────────────────────────────────────────┐
│   path      <str>  Target directory for the shared team knowledge instance  │
│                    [default: ./team-knowledge-studio]                       │
└─────────────────────────────────────────────────────────────────────────────┘
┌─ Options ───────────────────────────────────────────────────────────────────┐
│ --name                               <str>  Human-readable team name        │
│                                             (defaults to the folder name).  │
│ --set-default    --no-set-default           Register this folder as the     │
│                                             active KB (default: only when   │
│                                             none exists).                   │
│ --git            --no-git                   Initialize a Git repository for │
│                                             shared team history.            │
│                                             [default: git]                  │
│ --upgrade                                   Refresh bundled assets while    │
│                                             keeping team knowledge files    │
│                                             intact.                         │
│ --force                                     Scaffold into a non-empty       │
│                                             directory that is not already a │
│                                             knowledge base.                 │
│ --help                                      Show this message and exit.     │
└─────────────────────────────────────────────────────────────────────────────┘

 without re-running full `oks init`.
