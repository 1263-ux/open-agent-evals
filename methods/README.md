# Methods

Method assets live in `methods/<slug>/method.yaml`, using the fields from `specifications/method-card.schema.yaml` and the starter in `templates/method-card/`.

A method states what it is for, where it does not apply, and which experiment records support it. Status advances only with evidence: `proposed -> experimental -> verified -> recommended`, per `GOVERNANCE.md` §3–§4. A method with no experiment records cannot exceed `proposed`.

No method has been promoted yet. The first candidates come from `experiments/`, not from general practice.
